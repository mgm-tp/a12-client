[#/features/modelgraph]
= Model Graph

The Model Graph provides information about Models during runtime.

The following Client features make use of the Model Graph and therefore require you to load and set it:

|===
|Feature|Reason
|<</features/heterogeneity, Heterogeneity>>|lookup of supertype relations
|<</advanced/model-loading, Model loading>> (when using the default `ModelLoader` implementation provided by Client.footnote:[It is technically possible to use the `ModelLoader` API without a Model Graph, but this requires you to write your own implementation to resolve model references some other way.])|resolving model references
|===

You can load the Model Graph yourself from any place, but most probably you want to use the respective A12 Services API to load it from an A12 Server. A simple and safe occasion is immediately after the user logged in. Please refer to link:/docs/data_services/dataservices-documentation-src/index.html#rest_get_model_graph[the Services documentation] for more information.
